A make.fun entry for **One Line, One Laugh: Roast Your Fridge**. The program writes a single original roast line — one line, under 200 characters — to `/output/entry.txt`. The line roasts the fridge's crisper drawer, the drawer where vegetables go to be identified by their next of kin.

## Run it

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt`.
